If you used the IBF Portal, most of what you know still applies. This page maps the differences so you are not looking for things where they used to be.

!!! Note "Added to the agreed outline"
    This page was not in the original outline. It is included because the pre-release audience is existing IBF users. Remove it if you would rather keep the release section to one page.

### What stays the same

- The platform still shows impact based forecasts: hazard, exposed population, admin areas, thresholds
- Alert levels and the concept of a trigger work the same way
- The decision to act still sits with your National Society and your protocol
- Forecasts still come from external providers, not from us

### What changes

| In IBF | In National Risk Watch |
| :--- | :--- |
| One portal instance per country | One platform for all National Societies, centrally hosted and maintained, configured per country |
| Single hazard focus per instance | Multi hazard by design, with hazards added over time. Floods only in this pre-release |
| Data sources not visible in the interface | Every event lists the datasets it was built from |
| Alerts grouped as separate warnings | One event per region, updated as forecasts change, rather than a new entry per forecast run |
| Portal only | A standalone platform plus a National Risk Watch view inside IFRC GO. This manual covers the standalone platform |

### Things you had in IBF that are not here yet

Alert emails, login, exports and hazards other than floods. See [What is not yet available](./not-yet-available.md) for the full list and status.
