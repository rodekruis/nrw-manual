Terms used in National Risk Watch and in this manual.

| Term | Meaning |
| :--- | :--- |
| **Admin area** | An administrative unit in your country, for example a region, district or the level below. Admin levels available in the platform follow the boundary data loaded for your country. |
| **Advisory** | The short line on an event card reminding you what your protocol expects at this alert level. Not an instruction from the IFRC or the Netherlands Red Cross. |
| **Alert level** | How severe and how likely a forecast situation is: low warning, medium warning or high warning. Combines return period and probability. Colors are fixed. Not the same as a trigger. |
| **Anticipatory action** | Acting on a forecast before a hazard hits, usually under a pre agreed protocol with pre agreed funding. |
| **Early Action Protocol (EAP)** | A pre agreed plan setting out what a National Society does, where, and at which forecast threshold. |
| **Early warning, early action** | The broader practice of using warnings to act earlier, whether or not a formal protocol exists. |
| **Ended** | Status for an event that is in the past. Not shown in this pre-release. |
| **Ensemble** | The set of forecasts a model produces from slightly different starting conditions. GloFAS runs 51. The probability of a given severity is the share of them that cross its threshold. |
| **Event** | One hazard situation in one region of your country, opened when a forecast crosses a threshold and updated as forecasts change. |
| **Event created** | When the platform first opened the event, meaning when monitoring of it began. Not when flooding starts. |
| **Exposed population** | The estimated number of people inside the area a hazard is forecast to reach. For floods, people in water forecast to be at least 10 cm deep at the peak. Not the total population of the admin area. |
| **Flood depth** | How deep water is expected to be at the peak of an event. The name of the blue map layer, whose edge is also the area the flood is forecast to reach. Only produced for events reaching the trigger return period. |
| **GloFAS** | The Global Flood Awareness System, run by Copernicus. The only river discharge forecast source for now. Produces 51 forecasts per day per station, out to 7 days. |
| **Imminent** | Status for an event that is in the future. The window in which early action is possible. |
| **Impact based forecasting** | Combining a weather or hydrological forecast with historical data and population data to estimate what the weather will do, not only what it will be. |
| **Lead time** | The number of days between now and the forecast event. A trigger requires a minimum lead time, because actions need time to be delivered. |
| **Ongoing** | Status for an event that is happening now. |
| **Peak** | The highest forecast value in the forecast window, and the date it is expected. |
| **Probability** | How likely a given severity is, measured as the share of the 51 model runs that cross its threshold. Shown alongside severity, because the two move independently. |
| **Return period** | How rare a forecast level is, based on the historical record at that location. A five year discharge is reached on average once every five years. Rarer means more severe. |
| **River discharge** | The volume of water passing a point in a river each second, in cubic meters per second (m3/s). |
| **Standalone platform** | The version of National Risk Watch that opens in its own window, without an IFRC GO account. What this manual describes. |
| **Station** | The GloFAS measurement point on a river whose discharge forecast an event is built around. One station per event. |
| **Threshold** | The forecast value at which an alert level changes or a trigger is reached. Drawn on the discharge graph as return period lines. Set per country and derived per location from that location's own history. |
| **Total population** | Everyone living in an admin area, whether or not the hazard is forecast to reach them. Not shown in this release. |
| **Trigger** | The point at which your protocol's activation conditions are met: the required return period, at the required probability, with at least the required lead time. Shown on the event card as **trigger reached**. Separate from the alert level, not a level above it. |
| **WorldPop** | The 100 m constrained population grid used to calculate exposed population. |
